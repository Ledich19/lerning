# Архитектура ПО

Корневая страница курса архитектуры в общем учебном репозитории. У других направлений — собственные папки и README.

## Навигация

- [Документация, заметки и ссылки](docs/README.md)
- Задания и исходный код каждого занятия — в отдельных подпапках: `01-responsibilities`, `02-...`.

## Работа

- Перед решением: `git pull`. После решения: коммит и `git push`.
- Для проверки отправить в чат архитектуры ссылку на коммит или pull request.
- Этот чат меняет только `architecture/`. Другие направления ведут свои папки.
- Программа, оценки, ошибки и повторения остаются в общей системе Notion; ссылки находятся в [docs](docs/README.md).

## Текущее занятие

Ответственность, связность и зацепление. Обсуждение начато в чате; исходный код задания ещё не перенесён.

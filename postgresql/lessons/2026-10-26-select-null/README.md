# Повторение: SELECT и NULL

Тема: `NULL`, `UNKNOWN`, группировка `AND`/`OR`.

Задание создано как самостоятельная повторная попытка после предыдущих ошибок. Плановое время: 20–30 минут.

## Подготовка

1. Выполни `git pull`.
2. Запусти `task.sql` в PostgreSQL.
3. Заполни секции с `TODO` в этом файле.
4. Закоммить и отправь изменения.
5. Передай ссылку на коммит для проверки.

## Задания

1. Напиши запрос, который выводит `id`, `name`, `region`, `debt` для клиентов, одновременно удовлетворяющих условиям:
   - регион отличается от `'UA'`, причём `NULL` тоже включается;
   - долг неположительный (`<= 0`), причём `NULL` тоже включается;
   - сортировка по `id ASC`.

2. Не запуская три контрольных запроса из `task.sql`, запиши ожидаемые `id`. Для исключённых строк укажи, где условие дало `FALSE`, а где `UNKNOWN`.

3. Кратко объясни:
   - чем `NULL` отличается от пустой строки `''`;
   - почему `column <> value` не включает строки с `NULL`.

## Критерии

- Основной запрос выполняется в PostgreSQL.
- Две группы условий соединены через `AND`.
- Учтены `0` и оба случая `NULL`.
- Верно предсказаны результаты трёх контрольных запросов.
- Объяснены `UNKNOWN` и отличие `NULL` от пустой строки.
- В фильтре не перечисляются конкретные `id`.

Для освоения темы нужны минимум 4/5 и выполнение всех обязательных критериев.

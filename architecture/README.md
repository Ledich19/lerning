# Архитектура ПО

Папка курса архитектуры в общем учебном репозитории.

## Работа

- Задания и исходный код каждого занятия размещаются в отдельной подпапке: `01-responsibilities`, `02-...`.
- Перед решением: `git pull`. После решения: коммит и `git push`.
- Для проверки отправить в чат архитектуры ссылку на коммит или pull request.
- Этот чат меняет только `architecture/`. Другие направления ведут свои папки.
- Программа, оценки, ошибки и повторения остаются в общей системе Notion: https://app.notion.com/p/3feb37726d4f813ca71be9561262e3d8

## Текущее занятие

Ответственность, связность и зацепление. Обсуждение начато в чате; исходный код задания ещё не перенесён.

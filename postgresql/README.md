# PostgreSQL, SQL и проектирование баз данных

Корневая страница курса баз данных в общем учебном репозитории. Другие учебные направления используют собственные папки и README.

## Навигация

- [Документация, заметки и ссылки](docs/README.md)
- SQL-задания, исходные данные и решения каждого занятия — в отдельных подпапках: `01-select-null`, `02-joins` и далее.

## Работа

- Перед решением: `git pull`. После решения: коммит и `git push`.
- Для проверки отправить в чат PostgreSQL ссылку на коммит или pull request.
- Этот учебный чат работает только в `postgresql/` и не меняет другие направления.
- Задания, SQL и тестовые данные хранятся в GitHub, без дублирования полного текста в Notion.
- Программа, оценки, ошибки и даты повторения — в общей системе Notion.

## Текущая тема

`SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `NULL` и трёхзначная логика. Первая практика проведена в чате; последующие файлы заданий размещаем в подпапках курса.
